# Bondhu Pharmacy - Feature List

## MVP Features (Launch Day)

### For the Customer
*   **App Installation:** PWA installation prompt ("Add to Home Screen" on Android/iOS).
*   **Medicine Catalog:** Browse a list of available medicines with pricing.
*   **Search Engine:** Simple text search to find medicines quickly.
*   **Shopping Cart:** Add, remove, and update quantities of medicines before checkout.
*   **Wishlist:** Save medicines for future purchases without adding them to the cart.
*   **Checkout:** 
    *   Simple form to collect Name, Phone Number, and Delivery Address.
    *   Cash on Delivery (COD) as the default payment method.
*   **Notifications:** Receive general broadcast push notifications (e.g., "New stock of Paracetamol arrived!", "Discount on baby products").

### For the Admin (Pharmacy Owner)
*   **Order Notifications:** Receive an SMS/Email or Firebase notification when a new order is placed.
*   **Manual Order Management:** Admin will manually call the customer to confirm the order and arrange delivery for the MVP phase.

---

## Phase 2 Features (Next Update)

### For the Customer
*   **User Authentication:** Login/Signup using Phone Number OTP (One-Time Password).
*   **Profile Management:** Save delivery addresses and view past order history.
*   **Prescription Upload:** Take a picture of a doctor's prescription and upload it. The pharmacy will review it and add the medicines to the cart/order.
*   **Order Tracking:** Live status of the order (Pending, Processing, Out for Delivery).
*   **Personalized Notifications:** Notifications specific to the user's order status.

### For the Admin (Pharmacy Owner)
*   **Admin Dashboard:** A secure web page to manage operations.
*   **Catalog Management:** Add, edit, or delete medicines, update prices, and mark items as 'Out of Stock'.
*   **Order Management Pipeline:** Change order statuses, view prescription uploads, and calculate total daily sales.

---

## Phase 3 Features (Future Expansion)

*   **Online Payments:** Integration with bKash, Nagad, or Cards for seamless online transactions.
*   **Promo Codes:** Ability to apply discount codes during checkout.
*   **Medicine Reminders:** In-app feature where users can set alarms to take their medicines.
*   **AI Chatbot:** A basic automated chat assistant to answer common questions like "Do you have medicine X?".
*   **Native App:** Release on Google Play Store as a standalone APK.
